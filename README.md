Personal portfolio for Souvik Chakraborty, a final-year B.Tech Computer Science & Engineering student (2026) focused on backend engineering and AI-powered applications.

## Stack

- React 18
- Vite
- Tailwind CSS
- Motion

## Setup

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The app runs at `http://localhost:5173`.

## Scripts

```bash

npm run build

# Preview the production build

npm run lint
```

## AI Chatbot (optional)

The portfolio includes an optional Groq-powered assistant. It is frontend-only and is not required to view the site.

1. Create a Groq API key from Groq Console.
2. Copy `.env.example` to `.env` and set:

```
VITE_GROQ_API_KEY=your_key_here
```

3. Restart the dev server.

Do not commit API keys. Keep the key private and rotate it if it is ever exposed.
